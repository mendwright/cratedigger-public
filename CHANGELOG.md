# Changelog

Cratedigger is a desktop Plex music client — a record-crate browser with deep
credits, casting to Plexamp, lyrics, and bios. This public build is read-only
against your library.

This repository is a published snapshot of the app, refreshed on each release.
For the per-release notes that drive in-app update prompts, see the
[Releases](https://github.com/jaybeaman/cratedigger-public/releases) page.
